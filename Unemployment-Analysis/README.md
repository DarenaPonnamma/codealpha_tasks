# CodeAlpha Unemployment Analysis with Python

## Project Overview

This project analyzes unemployment rate data in India using Python.
The analysis focuses on unemployment trends, the impact of COVID-19,
rural vs urban unemployment, state-wise differences, and seasonal patterns.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn

## Analysis Performed

- Data cleaning
- Exploratory Data Analysis
- National unemployment trend
- Rural vs Urban comparison
- COVID-19 impact analysis
- State-wise unemployment analysis
- Top 10 states with highest unemployment
- Seasonal/monthly unemployment patterns
- Labour participation vs unemployment
- Correlation analysis

## Dataset

The project uses the `Unemployment in India.csv` dataset.
